# 砖了个砖 · 本地试玩

无依赖、无外部素材请求的 HTML/CSS/JavaScript Demo。双击 index.html 可以直接玩；手机试玩时运行“启动试玩.cmd”，手机与电脑连接同一 Wi-Fi，在手机浏览器打开终端显示的电脑局域网地址。电脑必须保持运行。如果连接失败，请先检查是否为同一网络，以及 Windows 是否允许该 Node 进程的专用网络入站连接；脚本不会修改防火墙。

## 已实现

- 10×14 经典棋盘、6×8 轻松棋盘、留白练习棋盘；图案总数为偶数。
- 新局经典模式有 48 类图案（26 类各 2 块、22 类各 4 块）；轻松模式有 16 类（各半为 2 块和 4 块）。每类最多 4 块，旧存档保留，新开一局生效。
- 单击可直接消除同一直线上无遮挡的同类；无目标时同类抖动，多个目标时选择。
- 鼠标/触屏拖动；锁定一个轴；只有拖动开始时沿移动方向连续相连的砖块一起移动，跨过空格后遇到新砖块会被阻挡，不会将其加入推动队列。
- 连续跟手拖动，当前行列高亮；可以经过任意匹配位置继续移动，仅按松手时的对齐位置消除。多个候选松手后选择，两块同时炸开。
- 被推动的其他砖块保留在消除时的位置；未消除的拖动回弹。
- 提示枚举直接消除和带推动的直线移动；死局定义为不存在这样的一步消除，死局才能打乱。
- 打乱保留占用位置和每类数量，保证至少存在下一步；不保证整盘无需再次打乱即可解完。
- 清空胜利、连击视觉反馈、撤回、新局确认、localStorage 自动存档。

## Demo 的明确约定

录屏只有约 21 秒，未完整演示所有边界。本 Demo 将“推动”解释为可推动连续队列；未匹配回弹，成功时被推动者停留。根据试玩反馈，直接配对改为单击触发，拖动匹配需等待松手。连击间隔暂定 5 秒，不宣称是原版数值。练习和撤回为本地辅助功能。无广告、付费、账户、排行榜。网页没有实现 PWA 离线安装；本机直接打开 HTML 可离线玩。

运行规则检查：`node engine.test.cjs`。
运行拖动交互回归检查：`node motion.test.cjs`（覆盖连续跟手、按住不消除、松手双爆、取消回滚、多目标选择）。
